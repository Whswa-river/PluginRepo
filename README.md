# River's Dalamud Plugin Collection

River 的 Dalamud 插件合集仓库。

## 插件列表

| 插件 | 描述 | 版本 |
|------|------|------|
| RiverBox | RiverBox 自用插件 | 1.0.8.0 |
| AutomaticHunting | 自动狩猎跟车 (暂不维护) | 1.0.4.0 |
| AllPotPredictor | 全大区魔法罐预测 | 1.0.0.0 |

## 安装方法

在 Dalamud 中添加插件仓库：
```
https://raw.githubusercontent.com/Whswa-river/PluginRepo/main/plugins.json
```
